# Thai Imbiss Nam Fon — animierter Website-Entwurf

Entwurf einer animierten Restaurant-Website für einen erfundenen Imbiss: Speisekarte, Partyservice, Über uns, Kontakt. Animationen mit GSAP.

Alle Namen, Adressen und Kontaktdaten sind fiktiv.

- **Live ansehen:** https://kira-moewes.github.io/thai-imbiss-nam-fon/
- **Technik:** eine einzige HTML-Datei (HTML, CSS, JavaScript), ohne Framework und ohne Build-Schritt. Lokal öffnen: `index.html` im Browser.
